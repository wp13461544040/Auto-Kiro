📦 方案选择建议
------------------------------------------------------------

1. 快速测试 → Python 版本
   文件: waf_server_example.py
   优点: 安装简单,3分钟搞定
   缺点: 性能一般,仅用于测试
   
2. 生产环境 → Node.js 基础版 ⭐推荐
   文件: waf_server_nodejs.js
   优点: 高性能,低资源,与Go端算法一致
   缺点: 不生成真实指纹
   
3. 高级需求 → Node.js 高级版 ⭐⭐推荐
   文件: waf_server_advanced.js
   优点: 真实浏览器指纹,最高成功率
   缺点: 资源占用高

🚀 三条命令快速启动 (Node.js 基础版)
------------------------------------------------------------

第一步: 安装 Node.js
  下载地址: https://nodejs.org/ (选择 LTS 版本)

第二步: 安装依赖
  cd c:\Users\Administrator\Desktop\kiroX
  npm install

第三步: 启动服务
  npm start

完成! 服务地址: http://localhost:8888

🐛 常见问题
------------------------------------------------------------

Q: 启动失败?
A: 检查 Node.js 版本 >= 16
   npm install 重新安装依赖

Q: 端口被占用?
A: 修改 PORT 环境变量
   set PORT=9999 & node waf_server_nodejs.js

Q: 连接超时?
A: 检查防火墙
   检查服务是否启动: http://localhost:8888/health

Q: Puppeteer 启动失败?
A: Windows: npm install puppeteer --save
   Linux: 安装 Chromium 依赖 (见 README_WAF.md)
